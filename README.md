# Identity Platform

A from-scratch identity platform built incrementally with:

- React + TypeScript
- Spring Boot
- Gradle
- PostgreSQL
- Docker

The project evolves from basic authentication into a production-grade
authentication and authorization platform.

## Learning approach

Each phase introduces a real security or architectural problem.

We will:

1. Build a minimal solution.
2. Understand how it works.
3. Attack it.
4. Identify its weaknesses.
5. Improve the design.
6. Add tests and documentation.

## Phases

- Phase 0 - System foundations
- Phase 1 - Authentication core
- Phase 2 - Sessions
- Phase 3 - Token-based authentication
- Phase 4 - Authorization
- Phase 5 - OAuth 2.x / OpenID Connect
- Phase 6 - MFA and Passkeys
- Phase 7 - Multi-tenancy
- Phase 8 - Distributed identity infrastructure
